## The Core Problem

The Python numpy backtest uses OHLC M1 data and simulates fills at bar close
prices — it has **zero spread cost, zero slippage, zero fill latency**. The
MT5 "Every Tick" backtest models actual tick-level fills with broker spreads,
requote handling, and order queue semantics. **The gap between these two is
the "tick execution gap"** — quantifying it tells you if your strategy's
Python win rate survives real trading conditions.

## V2z Strategy Summary

- **Logic**: z-score mean reversion on M1 bar closes
  - Z_WINDOW=50: compute returns of last 51 closes (50 prior + 1 current)
  - z = (current_return − mean(50 prior returns)) / std(50 prior returns)
- **Entry**: when |z| ≥ Z_THRESHOLD, fade: z>0 → SHORT, z<0 → LONG
- **Stop**: ATR(20)-based trailing, STOP_A × ATR as initial stop
- **Trail**: TRIG_A × ATR to activate, GAP_A × ATR offset
- **Expiry**: MAX_HOLD_BARS (=54) max bars held
- **Pairs**: EURUSD, GBPUSD, EURJPY, USDJPY, EURAUD, EURNZD, GBPAUD,
  GBPCAD, GBPNZD, AUDNZD, AUDCAD, NZDCAD (and any subset)

## Python vs MQL5 Mapping

| Aspect | Python (hfdf_m1) | MQL5 (V2z_CPPF) |
|--------|-----------------|------------------|
| Data | numpy OHLC M1, CSV | MT5 CopyClose/CopyHigh/CopyLow |
| Z-score | 50 prior returns + 1 current | same: BUF_SZ = Z_WINDOW+2 |
| Entry | on bar close (t+0 close) | OnTick → IsNewBar → CheckEntry |
| Fill | close price (ideal) | SymbolInfoTick ask/bid |
| Spread | 0 | live spread via GetSpreadPips |
| Stop | ATR(20) trailing | same, via ModifyStopLoss SLTP |
| Trail | TG/GP trail | same |
| Expiry | 54 bars | MAX_HOLD_BARS |

## ⚠️ Critical: UTF-8 BOM Destroys .set Files

The most insidious bug: **PowerShell `-Encoding UTF8` adds a BOM** (`239 187 191`)
that MT5 silently ignores. The EA runs with compiled-in defaults — no error,
no warning. **Always use `-Encoding ASCII`** for `.set` files.

## ⚠️ Critical: Terminal Cache Kills Auto-Start

After the first backtest, the terminal caches tester state. Subsequent runs
with different configs are **silently ignored** unless:
1. Data directory is fully wiped (keep only MQL5, config, origin, Accounts)
2. `[Tester]` section is stripped from `terminal.ini`
3. INI config includes a `[Common]` section before `[Tester]`

## Quick Start

### One-liner (PowerShell)

```powershell
cd paper_trade\mt5_backtest
powershell -File run_v2z_backtest.ps1 -Symbols "GBPNZD" -ZThreshold "2.5"
```

### Manual Steps

```powershell
# 1. Compile EA (handled by terminal on startup, or manually in MetaEditor)
# EA at: MQL5\Experts\V2z_CPPF.mq5

# 2. Write BOM-less .set file
@"
Z_THRESHOLD=2.5
STOP_A=3.0
TRIG_A=0.5
GAP_A=0.1
"@ | Set-Content "$env:APPDATA\MetaQuotes\Terminal\D0E8209F77C8CF37AD8BF550E51FF075\MQL5\Profiles\Tester\V2z_CPPF.set" -Encoding ASCII

# 3. Run MT5 CLI backtest
python paper_trade/mt5_backtest/run_mt5_bt.py --pairs GBPNZD --mode backtest
```
